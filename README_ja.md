システム開発を学ぶプログラマー向けの体系的なパスで Rust を習得します。構文とデータ型から所有権、借用、ライフタイム、エラー処理、並行処理へ進み、安全な対話型 Rust プレイグラウンドの動画なし演習を通して、高速でメモリ安全かつ信頼性の高いプログラムを書く実践力を養います。
