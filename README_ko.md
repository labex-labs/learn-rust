시스템 개발을 시작하는 프로그래머를 위한 체계적인 경로로 Rust를 배우세요. 문법과 데이터 타입부터 소유권, 대여, 수명, 오류 처리, 동시성까지 단계적으로 익히고, 안전한 대화형 Rust 플레이그라운드에서 동영상 없는 실습으로 빠르고 메모리 안전한 프로그램을 작성하는 능력을 기릅니다.
